# RoyalThakur Temp Mail Service

A professional temporary email service with admin panel and UPI payments.

## Features

- ✅ User Registration & Login
- ✅ Temporary Email Generation
- ✅ Real-time Inbox
- ✅ Admin Panel with Full Control
- ✅ UPI Payment System
- ✅ API Management
- ✅ Responsive Design

## Installation

### 1. Prerequisites
- Node.js (v14 or higher)
- MongoDB
- Git

### 2. Clone & Setup
```bash
git clone <repository-url>
cd royalthakur-temp-mail
